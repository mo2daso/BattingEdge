Step 1 — Push to GitHub
Open Git Bash or the VS Code terminal in your project folder and run:


cd "d:/Users/Anoshia/BattingEdge_FYP"

git add .

git status
# Check nothing secret is staged (no .env file should appear)

git commit -m "Add theme toggle, CricBot, dashboard, settings, shot library, deployment config"

git push origin main
If it asks for credentials, log in with your GitHub username and a Personal Access Token (not your password).

Step 2 — Get Free Groq API Key
Go to console.groq.com
Sign up with Google (no credit card)
Click API Keys → Create API Key
Copy it — looks like gsk_xxxxxxxxxxxx
Step 3 — Deploy Frontend to Vercel
Go to vercel.com → sign up with GitHub
Click Add New Project
Import your GitHub repo
In Configure Project:
Framework Preset: Vite
Root Directory: frontend
Build Command: npm run build
Output Directory: dist
Environment Variables — add this:
VITE_API_URL = (leave blank for now — fill in after Render deploy in Step 5)
Click Deploy
Your URL will be battingedge.vercel.app (if that name is available — you set the project name when you create it).

Step 5 — Connect Frontend to Backend
Go back to Vercel → battingedge project → Settings → Environment Variables and add:

Key	Value

Then go to Deployments → Redeploy (or just push a small change to trigger it).

For Your Defense Demo (Safest Option — Free)
Run the backend locally during your presentation + use Cloudflare Tunnel for a permanent URL:


# Install once
winget install --id Cloudflare.cloudflared

# Run your backend locally, then in another terminal:
cloudflared tunnel --url http://localhost:8000
# → gives you a permanent URL like https://battingedge.cfargotunnel.com
Set that URL as VITE_API_URL in Vercel. Your laptop is the server during demo — no RAM limits, no cold starts, full 94.71% accuracy.
